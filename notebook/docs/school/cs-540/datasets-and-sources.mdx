### Catches to remember

**FMCSA Company Census File**

- Self-reported on the MCS-150. FMCSA asks carriers to update every 24 months, and many don't.
- Counts sit at the carrier's physical address state, not where the trucks run.
- Typos are real: one carrier reported 858,001 power units. Cap or check before summing.
- "Power units" means trucks plus tractors. Trailers are counted separately.
- The Motor Vehicles cargo flag is broad. Over half of those carriers also flag general freight.
- It doesn't say whether a trailer is open or enclosed, or how many cars it holds.
- The open data API supports filters (for example active status and a cargo flag), so you can pull a subset instead of the whole file.

**FAF5**

- Tons are modeled estimates, not counts.
- SCTG 36 is "motorized and other vehicles," which includes parts.
- In-state flows (origin equals destination) are a large share. Don't double count them when you add outbound and inbound.
- The full state file is large. Filter to the commodity you need first.

**Census population**

- Includes the U.S., regions, states, and Puerto Rico in one file. Filter by summary level.
- Read with `encoding="latin-1"` because of accented characters.

**FRED series**

- Different frequencies. Average the weekly series to monthly before joining.
- Units differ (dollars vs. an index). Index both to the same base period to plot them together.

**VIUS 2021**

- Survey sample, so small subgroups are thin. The stinger-steered auto rack estimate (about two-thirds of tractor-pulled auto racks) came from only 235 sample records.

## Picking a public data source (what the course stressed)

- Prefer the agency that collects the data, or its official open data portal.
- Read the methodology and footnotes before using a column.
- Note the date you pulled it and the date the source last updated.
- Write down what it does not measure, and say so next to any chart that uses it.

## Key takeaways

- Government open data is reliable about how it was collected, not about whether it fits your question.
- Most joins between federal sources need a crosswalk (FIPS to postal code, weekly to monthly).
- Write the catch next to the source, because it's the first thing you forget.
