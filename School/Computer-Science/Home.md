# Master's in Computer Science

This section contains class notes, weekly learning workspaces, and assignment drafts for the master's program.

## Structure

- [Classes](Classes/README.md): one page per class, with links to notes and recurring assignments.
- [Journals](Journals/README.md): submission drafts written in Markdown.
- [Scripts](scripts/README.md): weekly workspace tools.

## Journal Workflow

1. Write and revise the journal in Markdown.
2. Copy the finished text into the prepared submission template.
3. Verify the required font, spacing, margins, and page count.
4. Submit the final document.

## Weekly Learning Workflow

Keep each week's learning and deliverable together. Generate the workspace, work from its `README.md`, and use `findings.md` as the topic index.

```powershell
.\newweek
```

Answer the short prompts; pressing Enter accepts the suggested course and next week. Command-line flags remain available when you want to skip the prompts.

The workflow is intentionally small: preview, select the ideas that matter, explain them using plain English and familiar examples, retrieve them from memory, and then write the assignment.
