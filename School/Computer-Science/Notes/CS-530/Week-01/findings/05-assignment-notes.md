## Scenario: game studio AI applications
Imagine a game studio wants to improve its player support and game experience systems. It needs to handle several different tasks at once: classify player support tickets, predict subscription churn, detect bots, recommend gear upgrades, and generate NPC dialogue.

### 1. Classify player support tickets
- Best approach: traditional machine learning
- Why: This is usually a structured classification task. The studio can use labeled examples of past tickets and train a model to sort new tickets into categories such as billing, account access, or technical issues.
- OSRS analogy: This is like sorting player complaints into categories such as account problems, item loss, or game mechanic confusion.

### 2. Predict subscription churn
- Best approach: traditional machine learning
- Why: Churn prediction often uses structured data such as play frequency, subscription history, payment behavior, and recent activity. A simpler model may be enough and easier to explain.
- WoW analogy: This is like identifying players who are likely to stop paying for a subscription based on fewer logins, less raid participation, and declining engagement.

### 3. Detect bots
- Best approach: deep learning
- Why: Bot detection often depends on subtle patterns in behavior that are hard to capture with simple hand-built rules. A deep learning model can analyze many signals such as movement patterns, response timing, and interaction habits.
- OSRS analogy: This is like spotting suspicious players who behave unlike normal humans, such as repeated movement patterns or suspiciously perfect farming routines.

### 4. Recommend gear upgrades
- Best approach: deep learning or traditional machine learning depending on the data
- Why: If the data is structured and the studio wants interpretability, traditional machine learning may be appropriate. If the system needs to learn from large amounts of player behavior and item usage patterns, deep learning may perform better.
- WoW analogy: This is like recommending gear upgrades based on a player’s class, role, raid history, and combat performance.

### 5. Generate NPC dialogue
- Best approach: generative AI
- Why: This task is about creating new text that resembles existing dialogue. Generative AI is the most appropriate choice because the goal is not just to classify or predict, but to generate new content.
- OSRS analogy: This is like having a system write new NPC lines, quest text, or flavor dialogue that sounds consistent with the game world.
