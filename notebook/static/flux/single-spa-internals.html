01 / START

single-spa core v6.0.3 · how it works

One array of registered apps, each with a status string. Whenever the URL might have changed, core calls reroute(): activity functions sort apps into unload / unmount / load / mount buckets, then promise chains move each status forward. Core never fetches a script, places apps in the DOM or reads an import map.

getAppChanges(): four buckets
