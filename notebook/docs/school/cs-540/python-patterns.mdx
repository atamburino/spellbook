## Key takeaways

- Load as text when IDs matter, then convert on purpose with `errors="coerce"`.
- Check keys before merging, use `validate=` and `indicator=True` during, and assert row counts after.
- Cap outliers with `quantile` plus `clip`, and say how many rows you capped.
- Titles say the finding. Color highlights one thing. Gray is for context.
- Finish every notebook with asserts so a silent problem stops the run.
