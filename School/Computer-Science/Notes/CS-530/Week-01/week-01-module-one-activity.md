## Assignment

Use GitHub Copilot in VS Code through Codio as a research partner to explore the relationship between machine learning and deep learning. The activity has two parts:

- **Part One: Chat Log** - submit a JSON file containing the interaction with GitHub Copilot.
- **Part Two: Analysis Report** - submit a 2-3 page Microsoft Word document using double spacing, 12-point Times New Roman font, and one-inch margins.

## Rubric Targets

### Part One: Chat Log

- Construct prompts that differentiate between machine learning models used in artificial intelligence.
- Construct prompts that explain the relationship between machine learning and deep learning in artificial intelligence applications.

### Part Two: Analysis Report

- Analyze the relationship between machine learning and deep learning after engaging with GitHub Copilot.
- Evaluate GitHub Copilot's effectiveness in exploring AI concepts based on the interaction.

## Copilot Prompt Strategy

The prompts should make Copilot explain AI concepts clearly, compare model types, and provide examples. Since OSRS and World of Warcraft are familiar systems, ask Copilot to use game analogies as learning scaffolding while also identifying where each analogy breaks down.

## Opening Prompt

```text
I am completing a graduate computer science assignment about the relationship between machine learning and deep learning in artificial intelligence. Please act as a research partner. Give clear explanations, compare concepts, and include practical examples, but do not write my final report for me.

Use analogies from Old School RuneScape and World of Warcraft where helpful. I understand those games well, so compare AI concepts to things like skilling, raids, combat roles, gear progression, boss mechanics, professions, auction house behavior, NPC behavior, pathing, and player decision-making. Keep the analogies accurate, but also explain where the analogy breaks down.
```

## Prompt Set

### Machine Learning Model Types

```text
Differentiate between major machine learning model types used in artificial intelligence: supervised learning, unsupervised learning, semi-supervised learning, reinforcement learning, and generative models. For each one, explain what kind of data it uses, what problem it solves, give one real-world example, and give one analogy from Old School RuneScape or World of Warcraft.
```

### Model Family Comparison

```text
Create a concise comparison table that shows the differences between common AI and machine learning model families: decision trees, random forests, support vector machines, k-means clustering, neural networks, convolutional neural networks, recurrent neural networks, transformers, and generative adversarial networks. Include typical use cases, strengths, limitations, and one OSRS or World of Warcraft analogy for each model family.
```

### AI, ML, Neural Networks, and Deep Learning

```text
Explain the relationship between artificial intelligence, machine learning, neural networks, and deep learning. Use a nested explanation that shows which concepts are broader and which are more specific. Then explain the relationship using an Old School RuneScape or World of Warcraft analogy, such as comparing AI to the whole game world, machine learning to learned player strategies, and deep learning to complex raid mechanics or high-level optimization.
```

### Neural Network Concepts

```text
Explain how neural networks connect machine learning and deep learning. Define neurons, layers, weights, activation functions, training, loss functions, and backpropagation in plain language. Then explain each term using a World of Warcraft raid team or Old School RuneScape bossing analogy.
```

### Traditional ML vs. Deep Learning

```text
How is deep learning different from traditional machine learning? Focus on feature engineering, data requirements, model complexity, interpretability, computational cost, and performance on unstructured data like images, audio, and natural language. Include an analogy comparing traditional machine learning to manually planning a skilling route or gear setup, and deep learning to a system learning patterns from thousands of raids, boss kills, or PvP encounters.
```

### Generative AI

```text
Explain how generative AI relates to deep learning. Include examples such as large language models, image generation models, and transformer-based systems. Then explain generative AI through an OSRS or World of Warcraft analogy, such as creating a new quest guide, generating a raid strategy, designing a gear setup, or writing NPC dialogue based on patterns learned from existing examples.
```

### Applied Scenario

```text
Give me a scenario where a game studio wants to classify player support tickets, predict subscription churn, detect bots, recommend gear upgrades, and generate NPC dialogue. For each task, recommend whether traditional machine learning, deep learning, or generative AI is most appropriate and explain why. Use examples from OSRS or World of Warcraft systems where useful.
```

### Misconceptions

```text
What are common misconceptions about the relationship between machine learning and deep learning? Give at least five misconceptions, correct them, and include an OSRS or World of Warcraft analogy for each correction.
```

### Evaluation of Game Analogies

```text
Evaluate the usefulness and limitations of using video game analogies, especially Old School RuneScape and World of Warcraft, to understand machine learning and deep learning. Where do these analogies help, and where might they oversimplify the concepts?
```

### Report Takeaways

```text
Based on our conversation, summarize the key takeaways I should consider when writing my own analysis report. Include both technical takeaways and the strongest OSRS or World of Warcraft analogies that helped explain the concepts. Do not write the report for me.
```

### Copilot Effectiveness

```text
I also need to evaluate GitHub Copilot as a learning tool. Based on this conversation, what criteria should I use to evaluate your effectiveness in helping me explore AI concepts? Consider clarity, accuracy, depth, examples, limitations, and whether I should verify answers with outside sources.
```

## Analysis Report Outline

### Introduction

- State that the activity used GitHub Copilot as a research partner.
- Identify the main focus: how machine learning relates to deep learning.
- Mention that game analogies were used to make abstract concepts easier to reason about.

### Relationship Between ML and Deep Learning

- Explain that AI is the broadest category.
- Explain that machine learning is a subset of AI focused on systems learning from data.
- Explain that deep learning is a subset of machine learning based on neural networks with multiple layers.
- Compare traditional ML and deep learning using feature engineering, data requirements, model complexity, interpretability, and performance on unstructured data.

### Strong Analogy Ideas

- AI as the entire game world or game system.
- Machine learning as a player improving strategy through repeated experience.
- Supervised learning as training with labeled examples, like learning boss mechanics from guides with correct callouts.
- Unsupervised learning as finding hidden player groups or market patterns without predefined labels.
- Reinforcement learning as learning through rewards and penalties, like optimizing boss attempts or PvP decisions.
- Deep learning as a complex raid team or bossing system that learns layered patterns from many examples.
- Generative AI as creating new quest text, NPC dialogue, or raid strategy based on patterns learned from existing content.
